# Contributing

Thank you for considering contributing to TAT Guard.

## Development Setup

1. Clone the repository
2. Copy `.env.example` to `.env` and fill in values
3. Install dependencies: `pip install -r requirements.txt`
4. Run tests: `pytest`

## Code Style

- Follow PEP 8
- All regulatory constants must come from `facts.yaml`
- Every number in documentation must carry a fact ID

## Pull Requests

- One logical change per PR
- Include test coverage
- Update documentation if needed
